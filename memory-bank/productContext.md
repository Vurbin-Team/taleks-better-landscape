# Product Context

## Why This Project Exists
Ванильный рельеф Minecraft не даёт редких «открыточных» форм, например одинокой скалы-шпиля в море (в коде есть ссылка на «reference picture»: картинки в репозитории нет). Мод добавляет такие формы, не ломая ванильное побережье.

## How It Should Work
1. При старте мода читается конфиг `config/fantasy_terrain.properties` (при первом запуске копируется из встроенного шаблона).
2. При каждой выдаче noise router для настроек генерации мир оборачивает `finalDensity` в `TerrainDensity`.
3. `TerrainDensity` к ванильной плотности прибавляет плотность от включённых фич.
4. `sea_stacks` добавляет плотность столбом там, где шум 2D превышает порог, а континентальность попадает в прибрежную полосу. Плотность только положительная, поэтому береговую линию фича не вырезает, а только достраивает башни.

## User Experience Goals
- Игрок ставит мод и получает башни в воде у берега без настройки.
- Игрок может настроить частоту, высоту, ширину и положение башен в одном `.properties` файле, где каждый ключ описан комментарием.
- Удаление строки из конфига возвращает значение по умолчанию.
- После правки конфига нужен перезапуск игры (или переоткрытие мира).

- Биомы: `meadow`, `stony_peaks`, все 4 windswept (`windswept_hills`, `windswept_gravelly_hills`, `windswept_forest`, `windswept_savanna`). Заснеженные горы и вершины не трогать. Cherry grove не включать.
- Снег: верхние **10 блоков каждой горы** (от вершины вниз). Под ним **голубой лёд** (`blue_ice`), **5 блоков**.
- Тело горы ниже льда: градиент снизу вверх **туф → гравий → андезит → камень** (камень под льдом), с дизерингом. Градиент не заходит в снег.

- В снежной и ледяной зоне ровное остаётся снегом и льдом (трава туда не идёт).
- Глубина изменений от поверхности: **3-4 блока**.

## Решение по подходу
Пользователь: «если можно сделать Lithostitched, делай, если нет, то 3-й вариант» (своё Java-условие для surface rules).
Проверено по исходникам Lithostitched (GitHub `Apollounknowndev/lithostitched`, снимок «1.8.0 beta 1», ветка `cloche`, папка `src/shared/26.1`; сам jar 1.8.1 скачать нельзя, Modrinth закрыт): условия поверхности в 26.1 это только `all_of`, `any_of`, `biome`, `slope` (перепад высот 4 соседей внутри чанка). Условие `sample_density` есть **только** в исходниках 26.2, для 26.1 его нет. Условия «высота от вершины горы» нет нигде, значит чистым Lithostitched «верхние 10 блоков каждой горы» не сделать. Идём по варианту 3. Версия 1.8.1 могла отличаться от снимка, это не проверено.
Среда: сборки нет (нет доступа к Maven, Mojang, Gradle), Java-ядро можно проверить только `javac` самопроверкой; игровую проверку делает пользователь.

## Старый список вариантов (для справки)
Ветка 26.1 это датапак на Lithostitched без миксинов. Варианты для «снега от вершины»:
1. Java `Feature` (по образцу `ShoreShelfFeature`): читает высоты в окне вокруг чанка и переписывает верхние 3-4 блока. Окно ограничено загруженными чанками (порядка радиуса 16), поэтому «вершина» считается локально, на широких горах возможны ступени снеговой линии.
2. Чистый JSON, `add_surface_rule` как в `steep_rock_gradient.json`: снег и лёд по абсолютной Y. Без Java, но не «от вершины».
3. Свой `SurfaceRules` condition в Java, читающий поля плотности. Сложнее всех, не проверено в 26.1.
Ещё нужно решить: что делать с существующим `steep_rock_gradient.json` в этих биомах (заменить или оставить), и что с `windswept_savanna` и `meadow`: мод сам их горами не делает (инжекторы есть только для windswept_hills, gravelly, forest).
